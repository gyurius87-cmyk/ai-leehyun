# AI이현 사이트 이전 키트

이현님의 비서 제로가 정리한 키트입니다. 이 폴더를 Claude Code에 넘기면 시안 그대로 실제 사이트를 만들 수 있습니다.

## 들어 있는 것

| 경로 | 내용 |
|---|---|
| `DESIGN.md` | 색, 글꼴, 페이지별 화면 구성 (PC·폰), 제로 사용 규칙 |
| `data/timeline.json` | 공부타임라인 기록 (날짜별 블록) |
| `data/notes.json` | 공부노트 목록 (번호, 제목, 숫자) |
| `data/programs.json` | 만든 프로그램 목록 (지금은 비어 있음) |
| `content/notes/001-ai-brand-name.md` | 공부노트 #001 원고 |
| `assets/zero/` | 제로 표정 12개 (SVG) |
| `assets/favicon.svg` | 브라우저 탭 아이콘 (제로 기본) |

## 순서

1. 컴퓨터에 새 폴더를 만듭니다. 예: `ai-leehyun`
2. 이 `zero-kit` 폴더를 그 안에 통째로 넣습니다.
3. 그 폴더에서 Claude Code를 열고, 아래 프롬프트를 붙여넣습니다.
4. 미리보기가 뜨면 PC와 폰 화면을 확인하고 고칠 점을 말합니다.
5. 다 되면 "GitHub에 ai-leehyun 저장소를 새로 만들어서 올려줘"
6. Vercel에서 그 저장소를 불러와 배포합니다. (부리딩 때와 같은 방식, 무료 주소)

## Claude Code에 붙여넣을 프롬프트

```
zero-kit 폴더에 있는 DESIGN.md, data, content, assets로
"AI이현" 개인 기록 사이트를 만들어줘.

조건
- Astro로 만든 정적 사이트. 방문자가 볼 때 DB나 서버를 쓰지 않는 구조.
- 페이지: 홈(/), 공부타임라인(/timeline), 공부노트 목록(/notes),
  공부노트 글(/notes/001), 프로그램(/programs)
- 타임라인, 공부노트 목록, 카운터 숫자는 data 폴더의 json에서 자동으로 계산해서 표시.
  "일째"는 2026-10-10(한국 시간)을 1일째로 계산.
- 공부노트 글은 content/notes의 마크다운을 읽어서 표시.
- PC와 폰 화면은 DESIGN.md의 구성을 그대로 따르고, 한 페이지가 화면 폭에 따라 바뀌는 반응형으로.
- 폰에서는 메뉴를 화면 아래 탭바로.
- 링크 미리보기(OG 이미지, 제목, 설명)와 파비콘 넣기.
- Vercel 무료 플랜에 그대로 올릴 수 있게.
- 다 만들면 내 컴퓨터에서 미리 볼 수 있게 실행해줘.
```

## 오픈 뒤 기록 추가하는 법

제로가 대화 끝에 정리해 준 내용을 Claude Code에 붙여넣고 이렇게 말하면 됩니다.

```
data/timeline.json에 아래 기록을 추가하고 GitHub에 올려줘.
(제로가 준 내용 붙여넣기)
```

공부노트는 `content/notes/`에 새 마크다운 파일을 넣고 `data/notes.json`에 한 줄을 추가합니다.
GitHub에 올라가면 Vercel이 몇 분 안에 사이트를 자동으로 바꿉니다.
