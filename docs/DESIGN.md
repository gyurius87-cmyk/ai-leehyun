## 페이지별 구성

### 홈 `/`
1. 차콜 영역: 로고·메뉴 → 첫 문장(숫자 "0"만 옐로 + Mono) → 둘째 줄(제로 기본 얼굴 아이콘 + "제로") → 카운터 3개
   - 카운터: **일째**(옐로) / **공부노트** / **만든 프로그램**
   - 폰에서는 이 영역이 스크롤 없이 한 화면에 들어와야 함
2. 공부타임라인: 가장 최근 날짜 블록 1개 + "타임라인 전체 보기 →" + 오른쪽에 제로(정리 중) "오늘 기록은 이현님의 비서 제로가 정리했습니다."
3. 최근 공부노트: 카드 최대 3개 + "공부노트 전체 보기 →"
4. 푸터: 차콜, 로고 / "기록 정리 · 이현님의 비서 제로" / 인스타 링크

### 공부타임라인 `/timeline`
- 제목 아래 설명 "하루 한 블록. 중요한 것만 남깁니다." + 제로(정리 중) "이현님의 비서 제로가 기록합니다."
- 숫자 카드 4개: 총 기록일 / 연속 기록일(옐로 밑줄) / 공부노트 / 만든 프로그램
- 날짜별 블록: 왼쪽 `D2` + 날짜·요일, 오른쪽에 시간 + 한 줄 기록
- `link`가 있는 기록에만 "보러가기 →" 표시
- 기본은 최신이 위. "1일째부터 보기" 버튼으로 순서 뒤집기

### 공부노트 목록 `/notes`
- 제목 오른쪽에 큰 숫자 "1 편"(옐로)
- 카드: `#001 · D1` / 날짜 / 제목 / 한 줄 요약 / 걸린 시간·단계·도구 / 태그
- 공부노트 숫자는 실제로 올라간 글만 센다

### 공부노트 글 `/notes/001`
- 맨 위 차콜 안내 상자: 제로 기본 얼굴 + "이 글은 이현님의 비서 제로가 작성했습니다. 오늘 이현님과 함께 공부한 내용을 바탕으로, 따라 할 수 있는 방법으로 정리했습니다. (Claude 기반)"
- 메타 줄: `#001 · D1 · 날짜` + 태그
- 제목, 한 줄 요약
- 숫자 상자 3개(걸린 시간, 단계, 도구)
- 본문(마크다운). 본문 폭 760px
- 끝: "← 공부노트 목록" / 인스타 링크
- 폰: 상단에 "← 공부노트" 돌아가기

### 프로그램 `/programs`
- 제목 오른쪽 큰 숫자 "0 개"
- 숫자 카드 3개: 만든 프로그램 / 한 주에 아끼는 시간 / 지금도 쓰는 중
- 비어 있을 때: 점선 상자 + 제로(기다리는 중) "첫 프로그램을 아직 만들지 않았습니다. 만들면 무엇을, 며칠 걸려, 얼마나 아끼는지까지 숫자로 남깁니다."
