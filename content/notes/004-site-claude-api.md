## 0단계. Claude 안에서 만든 프로그램의 한계

처음 생각 병목 찾기는 Claude 안의 페이지(아티팩트)로 만들었습니다. 이 방식은 AI 비용이 **보는 사람의 Claude 계정**에서 나가서, 만든 사람은 0원입니다. 이현님 화면에서는 잘 됐습니다.

그런데 지인이 열자 이렇게 떴습니다.

![지인 화면: claude.ai에 로그인한 상태로 열어야 AI가 병목을 찾을 수 있어요](/notes/004/cap-01-login.png)

로그인을 해도, 안내 버튼을 붙여도 마찬가지였습니다.

![로그인하러 가기 버튼을 붙인 뒤에도 같은 문구](/notes/004/cap-02-still.png)

이 페이지는 Claude Code에서 만든 것이라, 다른 사람 계정의 AI를 빌려 쓰는 기능이 막혀 있었던 것으로 보입니다. 우회로(질문을 복사해 내 Claude 채팅에 붙여넣기)도 만들었지만, 이현님의 답은 분명했습니다.

> "지인이 이 홈페이지를 이탈해서 사용하는게 아니라 나와 같은 환경과 화면으로 사용을 했으면 좋겠어"

> **잘한 점** 우회로가 생겼을 때 "되긴 된다"에서 멈추지 않고, 처음 원했던 모습을 다시 말한 것. 그래서 진짜 해결책(API)으로 넘어갈 수 있었습니다.

## 1단계. 선택지는 두 개뿐이라는 걸 압니다

내 사이트(Vercel)에서 AI를 돌리는 방법은 둘입니다.

| 방법 | 방문자 | 비용은 누가 | 결과 |
|---|---|---|---|
| 방문자의 Claude 로그인 빌리기 | 로그인 필요 | 방문자 | **불가능.** "Claude로 로그인" 기능이 외부 사이트에 없음 |
| 사이트가 API 키로 부르기 | 로그인 없이 바로 | 사이트 주인 | 가능. 쓴 만큼 충전금에서 빠짐 |

> **주의할 점** Pro 구독과 API는 지갑이 따로입니다. API를 아무리 써도 Pro 사용량은 줄지 않고, 반대로 Pro를 결제했다고 API를 공짜로 쓸 수도 없습니다.

## 2단계. 충전하고 키를 만듭니다

API는 월정액이 아니라 선불 충전식입니다. 충전금이 0이 되면 멈추고, 자동 충전을 켜지 않으면 더 나가는 돈은 없습니다.

1. console.anthropic.com 가입 → Settings → **Billing**에서 카드로 충전 (자동 충전은 끄기)
2. Settings → **Limits**에서 월 사용 한도 걸기 (예: 10달러)
3. **API Keys** → Create Key → 키 복사

> **주의할 점** API 키는 법인카드 번호와 같습니다. 채팅창, 코드, 카톡 어디에도 붙여넣지 마세요. 코드에 들어가 GitHub에 올라가면 누구나 내 돈으로 AI를 쓸 수 있습니다. 키는 3단계의 Vercel 금고에만 넣습니다.

## 3단계. 키를 Vercel 금고에 넣습니다

Vercel의 **Environment Variables**(환경변수)는 코드 밖에 비밀값을 넣어두는 금고입니다. 서버 함수만 꺼내 볼 수 있고, 방문자에게는 보이지 않습니다.

![Vercel 설정의 Environments 화면. 여기서 Production을 누르거나, 왼쪽 메뉴 Environment Variables로 들어갑니다](/notes/004/cap-03-vercel-env.png)

1. Vercel 프로젝트 → **Environment Variables**
2. 이름 `ANTHROPIC_API_KEY`, 값에 키 → Save
3. Deployments → 맨 위 배포 ⋯ → **Redeploy**

> **잘한 점** 메뉴를 못 찾았을 때 화면을 캡처해 "여기 맞는지?"라고 물어본 것. Vercel처럼 메뉴가 자주 바뀌는 곳은 말보다 캡처가 정확합니다.

> **주의할 점** 키를 넣은 뒤 **다시 배포해야** 적용됩니다. 저장만 하고 바로 써보면 아직 키가 없는 상태입니다.

## 4단계. 코드는 Claude가 만듭니다

Claude가 만든 구조는 이렇습니다.

| 부분 | 하는 일 |
|---|---|
| 화면 (`/programs/bottleneck`) | 방문자가 걱정을 적고 버튼을 누름 |
| 서버 함수 (`/api/bottleneck`) | 금고에서 키를 꺼내 Claude에게 질문하고, 답을 화면에 돌려줌 |

여기에 안전장치 세 가지를 같이 넣었습니다.

- **질문은 서버가 만든다.** 방문자는 걱정만 보내고, Claude에게 갈 질문 문장은 서버가 만듭니다. 누가 이 통로로 다른 질문을 해서 내 돈을 쓰는 걸 막습니다.
- **한 사람 하루 5번.** 같은 사람이 계속 눌러도 비용이 튀지 않습니다.
- **월 한도.** 2단계에서 건 콘솔 한도가 마지막 안전망입니다.

## 5단계. 켜지지 않으면 원인을 화면에 띄웁니다

다시 배포하고 눌렀는데 이렇게 떴습니다.

![지금은 준비 중이에요](/notes/004/cap-04-ready.png)

"준비 중"은 키가 없을 때와 AI 연결이 실패했을 때를 같은 말로 보여주고 있었습니다. 그래서 문구 끝에 원인이 보이도록 고쳤습니다.

| 괄호 안 표시 | 뜻 | 할 일 |
|---|---|---|
| (키 없음) | Vercel에 키가 안 들어감 | 이름 철자 확인 후 다시 배포 |
| (AI 연결 401) | 키 값이 틀림 | 키 다시 복사해서 넣기 |
| (AI 연결 400) | 대부분 충전 전 | Billing에서 충전 |

그 사이 이현님이 다시 눌러 보니 **작동했습니다.** 처음에는 새 배포가 끝나기 전에 눌렀던 것으로 보입니다.

![사이트 안에서 바로 나온 결과](/notes/004/site-result.png)

> **더 좋은 명령** 처음부터 "안 될 때 원인이 화면에 보이게 해줘"라고 함께 요청하면, 막혔을 때 서로 추측하는 시간이 줄어듭니다.

## 6단계. 비용을 계산하고 지켜봅니다

비용은 글자 수(토큰)로 계산됩니다. 질문으로 보내는 양과 답으로 받는 양에 값이 매겨집니다.

| 모델 | 질문 100만 토큰 | 답 100만 토큰 | 생각 병목 찾기 1회 (추정) |
|---|---|---|---|
| Opus 5.5 (지금 쓰는 것) | 4달러 | 20달러 | 약 50원 |
| Haiku 5.5 (가벼운 모델) | 0.1달러 | 0.5달러 | 약 1~2원 |

5달러 충전이면 Opus로 약 140회입니다. 답의 깊이가 덜 중요하면 Vercel에 `BOTTLENECK_MODEL` 하나만 추가해 가벼운 모델로 바꿀 수 있습니다.

> **주의할 점** 처음에 말한 1회 20~30원은 계산을 다시 해보니 낮게 잡은 값이었습니다. 숫자가 중요한 결정이면 "가격표 기준으로 다시 계산해줘"라고 한 번 더 확인하세요.

남은 금액은 콘솔에 로그인해야 볼 수 있어서, 사이트가 직접 쓴 토큰을 세어 **남은 금액 추정**을 보여주는 AI이현 전용 애널리틱스도 만들었습니다.

> **잘한 점** "남은 금액을 사이트에서 보고 싶다"에서 그치지 않고 방문자, 클릭까지 한 화면에 묶자고 한 것. 프로그램 하나가 사이트 운영 계기판이 됐습니다.

## 정리. 어디서 만들지 고르는 기준

| | Claude 안의 페이지 | 내 사이트 + API |
|---|---|---|
| 방문자 | Claude 로그인 필요 | 로그인 없이 바로 |
| AI 비용 | 0원 (보는 사람 계정) | 내가 냄 (1회 1~50원) |
| 다른 사람이 쓰기 | 막힐 수 있음 | 누구나 |
| 어울리는 것 | 나만 쓰는 도구 | 공개하는 프로그램, 릴스로 데려올 손님용 |

## 복사해서 쓰는 첫 질문

```
내 사이트(Vercel)에 [프로그램 이름]을 넣고,
방문자가 로그인 없이 바로 AI를 쓰게 Claude API로 연결해줘.

- API 키는 코드에 넣지 말고 Vercel 환경변수로 쓰게 해줘.
- AI에게 보내는 질문은 서버에서 만들고, 한 사람 하루 사용 횟수를 제한해줘.
- 1회 비용을 가격표 기준으로 계산해서 알려주고,
  충전부터 키 넣기까지 내가 할 일은 하나씩 알려줘.
- 안 될 때는 원인이 화면에 보이게 해줘.
```
